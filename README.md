# 📚 درس‌خون (DarsKhoon)
### پلتفرم هوشمند برنامه‌ریزی درسی، مطالعه گروهی و گزارش‌دهی خودکار به تلگرام

«درس‌خون» یک وب‌اپلیکیشن جامع و مدرن برای دانش‌آموزان، کنکوری‌ها و دانشجویان است که امکان برنامه‌ریزی درسی، مطالعه گروهی همراه با همرسانی، رهگیری دقیق ساعات مطالعه، ثبت دروس اختصاصی، دریافت پیام‌های تشویقی و ارسال خودکار گزارش کار به تلگرام را فراهم می‌سازد.

---

## 🌟 قابلیت‌های اصلی سامانه

### ۱. پروفایل اختصاصی برای هر فرد (Multi-User)
- امکان تعریف چندین حساب کاربری و دانش‌آموز مستقل.
- انتخاب آواتار ایموجی اختصاصی، رشته و مقطع تحصیلی، شعار انگیزشی و تعیین هدف ساعات مطالعه روزانه.
- تغییر سریع بین کاربران جهت استفاده در تبلت یا کامپیوتر مشترک.

### ۲. محاسبه و نمایش دقیق میزان مطالعه (سنجش و آمار)
- **تایمر سه‌گانه حرفه‌ای:**
  - ⏳ **پومودورو (Pomodoro):** بازه‌های ۲۵، ۴۵، ۶۰ و ۹۰ دقیقه‌ای قابل تنظیم همراه با افکت صوتی تیک و زنگ پایان.
  - ⏱️ **کرنومتر آزاد (Stopwatch):** ثبت ثانیه‌به‌ثانیه پارت‌های درسی.
  - ✍️ **ثبت دستی (Manual Log):** ثبت سریع مطالعه‌های گذشته با درج زمان، مبحث و تعداد تست.
- **داشبورد تحلیلی:** محاسبه مجموع مطالعه امروز، درصد تحقق هدف روزانه با نوار وضعیت و نمودار تفکیک درصدی دروس.

### ۳. ثبت و مدیریت دروس فردی برای هر دانش‌آموز
- هر فرد می‌تواند دروس اختصاصی خود را تعریف کند (نام درس، رنگ نشانگر، آیکون اختصاصی و هدف هفتگی).
- رهگیری پیشرفت هفتگی هر درس به صورت گرافیکی.
- امکان افزودن و حذف دروس دلخواه.

### ۴. پاپ‌آپ جملات تشویقی و انگیزشی بعد از هر جلسه درس
- به محض اتمام زمان یا ثبت پارت مطالعه، پنجره تشویقی ظاهر می‌شود:
  - 🎊 افکت بارش کاغذ رنگی (Confetti Animation).
  - 🎵 افکت صوتی پیروزی (Synthesized Web Audio fanfare).
  - 💬 جملات تشویقی و انگیزشی از بزرگان و روانشناسی موفقیت تحصیلی.
  - 🔄 دکمه دریافت جملات بیشتر.
  - 📤 امکان ارسال فوری گزارش این پارت به تلگرام.

### ۵. مطالعه گروهی و همرسانی (Group Study & Sharing)
- ایجاد گروه‌های مطالعه با نام و توضیحات دلخواه.
- صدور خودکار **کد دعوت اختصاصی** برای هر گروه جهت عضویت دوستان.
- **جدول رده‌بندی زنده (Leaderboard):** رتبه‌بندی اعضای گروه بر اساس دقایق مطالعه روزانه و نمایش مدال‌های 🥇 🥈 🥉.
- **فید فعالیت‌های زنده:** نمایش آخرین وضعیت اعضای گروه («فلانی در حال خواندن زیست است»).
- اشتراک‌گذاری مستقیم لینک و کد دعوت گروه در تلگرام.

### ۶. ارسال گزارش مطالعه به تلگرام (Telegram Integration)
- **روش اول (اشتراک‌گذاری آنی در اپلیکیشن تلگرام):** با یک کلیک روی «اشتراک در تلگرام»، کارنامه فرمت‌شده شکیل در Saved Messages یا گروه درسی شما باز می‌شود.
- **روش دوم (ارسال مستقیم از طریق Bot API):** درج توکن ربات تلگرام و Chat ID برای ارسال خودکار گزارش‌ها.
- **ویرایشگر متن کارنامه:** امکان افزودن یادداشت‌های دلخواه قبل از ارسال.

## 🚀 نحوه اجرا

سامانه در حال حاضر بر روی پورت `5000` در حال اجرا است:
```bash
# آدرس اجرای برنامه:
http://localhost:5000
```

### دستورات توسعه:
```bash
# اجرای سرور بک‌اند و سرو نسخه نهایی
npm start

# یا در محیط توسعه زنده با Vite:
npm run dev
```

## 🛠 فناوری‌های استفاده شده
- **Frontend:** React 19, Tailwind CSS v4, Lucide Icons, Canvas-Confetti
- **Backend:** Node.js, Express, RESTful APIs, Local JSON Database Engine
- **Audio:** Synthesized Web Audio API (بدون وابستگی به فایل‌های خارجی)
- **Telegram:** Telegram Bot API + Telegram Web Share Protocol
